# Блог — страница со списком статей и пример статьи

Учебный проект для портфолио: адаптивная верстка страницы блога и отдельной страницы статьи.

## 🚀 Что внутри

- Главная страница блога со списком карточек статей
- Страница статьи с типографикой, изображениями и цитатами
- Адаптивная верстка (mobile-first): от 360px до десктопа
- Семантическая разметка (header, nav, main, article, aside, footer)
- Работа со шрифтами и иконками (favicon)

## 🛠 Стек

- **HTML5** — семантическая разметка
- **SCSS** — переменные, вложенность, миксины
- **CSS Grid / Flexbox** — раскладка
- **Адаптив** — media-запросы

## 📁 Структура проекта

- `blog.html` — страница блога
- `article.html` — пример статьи
- `scss/` — исходные файлы стилей
- `css/` — скомпилированные стили
- `images/` — картинки для статей
- `fonts/` — шрифты

## 💻 Как запустить

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/AlexErm-bot/gazprom.tech-blog.git
2. Откройте файл blog.html в любом браузере.
3. Для просмотра страницы article.html можно кликнуть на первую карточку на странице блога.
